# Voice-Based Assistant

## Week 4 – Speech-to-Text

This project is a voice-based assistant that accepts speech input from the user and converts it into text.

### Objective
- Capture voice input through the microphone.
- Convert speech into text using Speech Recognition.
- Display the recognized text.

### Technologies Used
- Python
- SpeechRecognition
- PyAudio

### Output
The system listens to the user's speech and displays the converted text on the screen.
